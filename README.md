# Полка гражданского права

Учебная среда и портфолио преподавателя. Темы курса стоят на полке корешками;
книга открывается прямо на месте — внутри конспект, ключевые статьи ГК и ссылки.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
npm run preview  # посмотреть собранное
```

## Где что править

| Что | Файл |
|---|---|
| Темы, конспекты, ссылки, мемы | `src/content/books.ts` |
| Имя, «обо мне», контакты | `src/content/profile.ts` |
| Цвета, шрифты, ритм, скорости анимаций | `src/styles/tokens.css` |
| Картинки мемов | `public/memes/` |

Как устроен проект, почему он выглядит именно так и что решено дальше —
в [`PROJECT_CONTEXT.md`](./PROJECT_CONTEXT.md).

## Деплой

Vercel, статическая сборка. `vercel.json` уже настроен на SPA-роутинг: прямые
ссылки вида `/book/sdelki` открываются корректно.
